# References and originality

The chart implementations, palettes, documentation and synthetic example data in this repository are original work released under MIT. No upstream templates, source code, screenshots, icons or fonts from the projects below are bundled.

Ideas studied include business-question-led composition, direct annotation, chart catalogues, repository previews and linked interaction:

- [Lieflat Charts](https://github.com/larashero3-dotcom/lieflat-charts): repository presentation and chart storytelling.
- [Diagram Design](https://github.com/cathrynlavery/diagram-design): explanatory hierarchy and visual relationships.
- [Vivid Figures](https://github.com/yjz211/vivid-illustration-skill): precision and figure composition.
- [Tableau dashboard showcase](https://www.tableau.com/data-insights/dashboard-showcase): analytical dashboard reading order.

These references are not endorsements or dependencies. Their own licenses govern their materials. Three numerical comparison datasets used in private development have been replaced with fresh original synthetic values for this public edition.

All palettes are original general-purpose color systems. All operating values are fictional and do not describe any company.

The mechanism index in `references/inspiration-library.json` links nine specific works discovered through [DKMECO](https://www.dkmeco.com/community/visual) and Tableau Public. It records observations, evidence boundaries and counterexamples. No workbook, image, template or implementation from those works is redistributed.
