使用方法与计算定义

从总览选时段，再点任一“服务 / 区域”按钮固定对象。图表仍保留整个筛选范围；细节区比较该服务的两个区域，受区域条件约束。直接点选度量按钮，在完成请求、错误次数、错误率、预算消耗、慢请求次数和慢请求占比之间比较同一对象。延迟图另有桶次数与桶占比。选择“当前度量降序”可追踪对象位置变化。完成后可保存状态、复原总览、恢复保存。

错误预算 = Σ完成请求 × 1%；消耗倍数 = Σ错误 ÷ 错误预算。错误率 = Σ错误 ÷ Σ完成请求；不平均各分钟错误率。慢请求占比 = Σ延迟>500ms请求 ÷ Σ完成请求。持续性为当前窗口逐分钟消耗>1倍的分钟数及最长连续分钟数，不是独立事故判定。

分位数桶：按累计计数首次达到p×总请求的桶报告。P50/P95/P99只定位桶，无法得到桶内精确毫秒值。所有桶包含全体完成请求，包含错误请求；延迟并非仅成功请求。

时段包含两端。放大只改变时间轴，筛选与导出范围不变。起始晚于结束时会得到空结果，可应用合法时段或复原。排序动画在同一量纲下保持对象ID；换单位时先收束再展开，期间暂停读数。导出与打印先同步到最新目标状态。系统“减少动态”运行时生效。
