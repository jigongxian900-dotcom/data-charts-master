# 5.4 动效试用：验证范围

2026-11-17。本轮发布的是实际动效接入与展示更新，不是任意业务任务95分或商业交付保证。展示数据均为原创合成数据。

## 新增入口

- SVG 场景生成：作者提供已核算的矩形/圆/线几何，复用共享 ChartMotion；当前帧续接、快速反向、减少动态。不同坐标/单位语义即时切换，不伪造跨单位中间量。缺报与范围退出不补零。
- RetainedRows：固定记录、固定行高、声明范围；保留同ID DOM和真实内部条长，动画只管行位置/透明度。业务计算及动态数值仍需作者与数值场景负责。
- KPI趋势/目标卡与统一有界路由；工程预检不自动证明数据正确、完整无障碍或审美。

## 本地实际验证

测试环境为 Windows 的无头 Microsoft Edge，未声称已覆盖全部浏览器或读屏器。测试入口支持标准Playwright，BROWSER_CHANNEL可覆盖；其他平台默认使用已安装的Playwright Chromium，其平台运行不由本次Windows证据代证。

| 保留行 | 两种固定值布局54项浏览器检查；另13项独立复核 |

独审发现的极大有限行高导致CSS静默折叠已在DOM写入前拒绝，并独立复验关闭。预检也保留了无按钮减少动态动画的反例修复。未把重复用例相加称为不同业务能力。

## 仍有边界

生成器不替作者核算数据与几何关系，不解析任意SVG路径、曲线拓扑或Canvas。行适配不做通用布局和业务聚合；客户端自行添加CSS入场动画可能破坏不重播约束。预检对select/input、动态图元语义及完整读屏体验仍需专用检查。漂亮演示不是全场景稳定质量的证明。
