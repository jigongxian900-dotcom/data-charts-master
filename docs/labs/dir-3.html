02 / 看增量

把增长，
拆回市场。

换成同一条零基线后，贡献的差别更清楚。八个市场仍全部保留，没有只挑好看的样本。

03 / 看同店

印尼在涨，
同店却在降。

总盘同比增长13.3%，同店同比下降6%。两个现象同时存在，值得继续核查。

−6.0%

印尼同店营业额同比。

缺少门店、价格和投入拆解，不能把差异直接归因于新店，也不能据此判断追加资源最优。
