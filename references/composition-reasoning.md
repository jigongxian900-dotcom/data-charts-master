# 从业务问题推导复合与变形图

图型名称用来沟通结果，不决定能力边界。先表达需要被共同看见的关系，再选标记、组合操作和坐标。图谱与灵感库提供可迁移机制；陌生任务可以生成新的renderer或沿用已有可视化库。

## 先形成一个可检验的构想

制作前用几句话说明以下判断，不要求额外长表单：

**读者要作的判断 → 必须共同看到的信息 → 原值与派生关系 → 标记及组合方式 → 尺度、对象与时间如何对应 → 普通表达会漏掉什么 → 如何验证。**

例如要同时比较当前规模、目标差额和两期改善，先确定三者是否属于同一对象、期间和单位。绝对差额与增长率不是同一量；可以沿同一类别对齐，以实心条、目标参照和独立百分比读数联合表达。组合的价值是读者无需跨页重新寻找对象，不能靠增加图层数量证明它更好。

只需要回答一个精确差额时，普通条形可能已经足够。确实需要多个信息共同判断时，主动设计图内组合；不因为目录没有对应名称就退回固定模板，也不把整页拼入几个无关图当作推导成功。

## 从信息关系选择组合操作

| 操作 | 何时有用 | 绑定与边界 |
|---|---|---|
| 叠加 | 同对象、同单位的实际与目标，观测与区间 | 明确共同零线/数轴；轮廓、实心和线型分别说明身份；遮挡时改错位或邻近标注 |
| 对齐 | 同一对象的规模、差额、比率需要一起看 | 按稳定对象ID连接，类别顺序一致；不同单位放在有名称的独立轨道；不能直接比较不同轨道长度 |
| 分面 | 多组趋势、分布或多指标需要比较 | 比绝对量时共享域；独立域只能比较形状并明示；按真实日期间隔定位 |
| 嵌套 | 总量与分项、容量与使用量属于明确的包含关系 | 父子加总、非负面积和分母可核对；不把相关的三个指标硬套为包含关系 |
| 拆解/连接 | 需要跟踪构成、真实流向或配对变化 | 配对需要稳定键；数量流需单位与守恒；同色、同名或相邻年份不自动构成流转 |
| 坐标变换 | 周期、方向或空间关系本身有意义 | 保留变换前的值与单位，说明起点、方向和投影；精确比较困难时加邻近条/点读数 |
| 层级展开 | 多层分类要兼顾总量、父子结构和局部构成 | 先验证无环、父节点存在、叶子覆盖及加总；明确每一层的分母，不把多个层级当独立总量相加 |
| 归一化 | 比较不同量纲的轮廓或形状 | 写明基期/范围/标准化公式并保留原值；比率不能直接加总或无权重平均 |
| 聚合/分箱 | 点遮挡或粒度过细，需看密度与分布 | 披露分箱边界、统计量、分母和排除；聚合图保留追溯到原始记录的路径 |

组合方案应能说清：主比较是什么，新增一层揭示了什么，读者怎样把它与主图的同一对象对应。若需要不断读图例才能恢复这些关系，先重排层次、邻近标注或拆分。

## 单位、粒度和时间先于几何

- 为每个量确定观察单位、期间、分母、聚合及有利方向。原始值、派生值和参考值分开命名；目标、上期和去年不因外观相同就混称。
- 图层之间按对象ID与期间键连接，不按行号拼接。各层能对齐的对象可能不同；在图旁披露有效成对覆盖，原始表保留未知值。
- 不齐期间保留真实日期间距和缺测。累计量、阶段存量、同批转化、周期内占比各有数据条件，不能为了接成曲线或流带而补造观察。
- 不同单位可以共享时间/类别轴，各有可读数轴或轨道。任意双轴缩放不能作为同步、相关或因果的证据。
- 指标定义缺失时，说明未知；可提出候选解释，但不冒充正式业务口径。合成测试也要声明定义，不能借“示意”掩盖编码矛盾。

## 变形时保留什么

### 极坐标与玫瑰类

半圆、整圆、折扇、改变起始角或保留内孔，通常是同一坐标变换的参数，不需要分别维护模板。角度表示类别、方向还是时间必须声明；类别没有周期意义时，环形只是布局选择。

区分两种量：半径长度编码与扇区面积编码。面积编码满足 `r² − r0²` 与数值成正比；有内孔时不能简单用 `r − r0` 或直接把值当半径再称面积。正负值可用明确的发散径向方案或直角坐标表达，不能取绝对值后冒充原构成。

角宽、排序和圆心位置变化也会影响读法。负数、未知分项或部分覆盖不能被静默归零。需要精确排序时，保留可核对的数值列或普通位置比较。

### 多变量复合标记

气泡饼图可由同一个对象的 `x/y`、总量与互斥分项组成：位置编码两变量，圆面积编码总量，扇区编码分项占比。分别给出位置单位、大小参照和构成图例。分项需与总量同口径；有未知分项时说明部分覆盖，不把已知部分重算为整体100%。

蝴蝶＋比率气泡、柱＋差额区间、趋势＋阈值与事件，也按相同方法推导。气泡大小如编码绝对变化，正负仍需单独表示；不能仅凭面积推方向。一个标记承担的量过多时，可分成共享对象轨道，保留联合判断的路径。

### 层级与区间

矩形树、旭日、多层圆环可共享层级分区：父节点的几何区间由子节点按同一数值规则分配。明确父值来自输入还是叶子加总；两者不一致时先处理数据合同。父子节点同时存在不代表得到更多独立观察，统计总量时避免重复计算。

甘特、区间棒与跨度带共用起止位置机制，但业务语义不同。甘特需要真实日期和观察截止时间；缺结束时间可声明右截尾，不能默认已完成。进度若无测量依据，保留未知，不从剩余长度编造完成率。

## 从灵感到自己的方案

需要新构图、陌生组合或变形时，按关系和机制查询[灵感库](inspiration-library.json)，结合[灵感使用](inspiration-use.md)阅读少量相关原作。记录可借的机制及不适用条件，再用自己的数据重新设计。

参考作品的截图用于理解，不成为交付图层。竞赛装饰、发现式交互和桌面密度是否适合本次业务，单独判断。作品获奖、收藏或被精选，是阅读线索，不替代当前图的适配性。

## 实现与交付

普通图已经合适时继续用现有六类助手。需要图内新组合或坐标变形时，按[开放renderer接口](custom-renderers.md)注册作者侧生成函数；同一函数族的参数变化无需新增基础kind。几何工具仅提供常用尺度与分区，不限制Agent使用其它算法、SVG或现有可视化库。

需要超出助手的交互时，可独立实现同源HTML。仍按相同合同交付原始源、派生说明、几何记录、手机阅读与稳定静态出口。新增标注应在构建/稳定渲染中形成，网页、打印、SVG是否等价要逐项核对。

## 评审看推导结果

新任务的说明与图必须一致：为什么联合表达、量与对象如何对应、变形保留了什么、普通备选为何不足。评审核新输入、变更期间/单位/缺失后的结果和真实尺寸；不因提到“极坐标”“复合图”或多写几条规则就加分。

接受复杂表达与拒绝不成立的复杂表达都可能体现自主判断。需要联合信息却仅换预置图ID，或本可直读却增加解码负担，均不能算成功。
