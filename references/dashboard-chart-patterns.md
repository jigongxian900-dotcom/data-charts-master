# 看板常用图：先补判断，再补装饰

KPI不是只把数字放进卡片。先明确这个数字代表哪个期间、对象和单位，读者要判断水平、变化、目标还是异常；卡片的趋势和比较必须服务该判断。

| 读者问题 | 适合的组合 | 必须保留的条件 |
|---|---|---|
| 当前多少，走势如何 | 大数值＋迷你趋势＋起止日期 | 当前值与趋势最后观测的口径关系明确；缺测断开，微型趋势不能冒充零基线面积 |
| 同比与环比分别怎样 | 当前值＋两条带名称的比较＋趋势 | 分别标本期/同期/上期；完整同期窗；上期为零不计算无穷增长，未知不写0 |
| 距离目标多少 | 子弹图＋实际/目标/差额/达成率 | 实际条、目标刻线、区间背景角色不同；背景阈值需有来源或明确情景假设 |
| 单项达成是否直观 | 进度圆环＋精确分子/分母＋超额说明 | 目标0或未知单列；大于100%的数值保留，圆环主圈可止于100但超额另显，不把120%画成80% |
| 多个不同单位指标达成如何 | 分面子弹/进度条＋各自单位 | 单位不同不能直接比较条长；统一达成轴需标归一化，不静默相加 |
| 两个群体各项结构有什么不同 | 蝴蝶/背靠背条形＋共同中心标签 | 左右是两个正数量，负坐标只作布局；两侧共用同单位同尺度，不能一侧自动缩放 |
| 多组值怎样并排比较 | 分组条、哑铃、区间比较 | 类别/系列身份固定；只强调相同对象的差，避免颜色每次排序重分配 |
| 观点分布偏向哪边 | 发散Likert | 若将中立拆半，说明拆分规则；百分比分母与缺失明确；分组样本数可查 |
| 当前与未来路径怎样区分 | 实际线＋目标线＋情景预测虚线 | 预测起点、方法/假设可见；预测不是已实现，输入没有区间就不伪造置信带 |
| 同批对象随时间怎样留存 | cohort三角矩阵＋分母/样本数 | 未到龄格不当零；每一行保持自己的基准群体，跨期平均须说明权重 |
| 多维关系有何取舍 | 平行坐标/气泡象限＋原始值 | 各轴单位/归一化方向明确；象限阈值不是自然规律；没有约束不写投入优先级 |
| 规模与占比同时怎样变化 | Marimekko/矩形构成＋两维图例 | 宽度与高度各有明确分母，面积能对账；不把多个不同比率简单相乘成未经定义指标 |
| 多指标变化从何查起 | 排名表内嵌趋势、同比/环比和目标 | 图与表共享数据；空值独立显示；排序后对象身份、选中行与导出一致 |
| 一个指标如何算出来 | 算术指标树 | 节点等式、单位与范围可核；算术关系不是因果关系，缺输入不能自动补齐 |

## 组合页的节奏

先放读者最需要的判断，再安排趋势、目标和分解。KPI卡有迷你线和比较时，避免再放一排完全重复的数字。相同时间轴的关联图可联动；不同单位优先共享时间轴的小多图，不能靠任意双轴制造同步。

品牌红是焦点角色，不默认代表风险、下降或未达标。目标完成是否有利还要看指标方向。看板可以使用卡片，但图谱展示不是生产系统；合成数据和示意筛选不能写成真实数据接通。

## 参考用法

Tableau官方 [KPI看板说明](https://www.tableau.com/kpi/what-is-kpi-dashboard) 强调指标、时间与目标的适配；[子弹图说明](https://help.tableau.com/current/pro/desktop/en-us/qs_bullet_graphs.htm) 区分主度量条与参照线/区间。实际优秀案例应另看具体图件与交互，不能仅凭官方精选标签就复制布局。

需要具体构图与组合阅读依据时，查 [Tableau案例阅读](tableau-dashboard-reading.md)。只看过预览的部分与实际嵌入状态分别记录。
