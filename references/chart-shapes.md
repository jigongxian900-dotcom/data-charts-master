# 三种图形表现

选好能回答业务问题的图，再用同一组数据给出三张可对照实图。三张共用数据、排序、起止、尺度和单位。区别应当在图形本身，例如柱体、端点、区间轮廓和观测标记。配色变化可以附加在任一种图形上。

[浏览同数据选样](../examples/chart-shapes/index.html)。

| 图型与阅读任务 | 内置选项 |
|---|---|
| 排名与差额，横条或竖柱 | 实心柱 `solid`、端点杆 `pin`、刻痕柱 `notched` |
| 观测随时间变化 | 折线 `solid`、观测点 `observations`、刻点折线 `ticks` |
| 观测在两维尺度的分布 | 圆点 `solid`、透底圆环 `rings`、菱形点 `diamonds` |
| 显示可加增量、净变动和小计 | 实块瀑布 `solid`、线框瀑布 `frame`、刻痕桥 `notched` |
| 组内部分与总量 | 色块拼合 `solid`、线框分段 `frame`、刻痕分段 `notched` |
| 样本密度和分位位置 | 箱体 `solid`、四分位粗轨 `rail`、四分位括号 `brackets` |

差额柱三种都守住零线和负值方向。观测点与折线共享支撑范围，折线跳过缺测。散点保留中心坐标，若大小承担第三变量，改形状时核对面积标尺。瀑布、构成和分位区间保留原来的两端。刻痕不代表独立观测。

自定义图按相同方法设计三版。例如流带可用实带、细描边带和带内明暗标注，宽度和端点关系保持一致。用版式、注释或交互辅助读数时，给出读者能感知的差别。首交给选样与推荐款，已经明确选定时在正式成稿中只使用该款。

`python scripts/build_chart_shape_gallery.py --input spec.json --output choices.html` 用同一输入生成内置图型的选样页。各款 SVG 可单独下载。在普通出图或报告合同的图对象上设置 `shape` 使用该样式。柱图可用 `orientation: "vertical"`；长标签或类别多时用横条。
