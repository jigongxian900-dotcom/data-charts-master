# 业务数据变化的两种动效接线

先单独打开 [单文件业务示例](../assets/motion-business-demo.html)：它在同一页面演示**数量排序条形图**和**目标达成圆环**，使用合成数据；单文件已内联 `chart-motion.js`、`retained-motion.js`，离线可打开。示例提供可读源码，但不是通用图表生成器。无头浏览器实测只覆盖这两张图的固定线性尺度和稳定 ID，不能据此断言新任务已达标。

先问有哪些对象被保留、进入、退出；哪些数值是在同口径、单位、尺度下可比较。保留对象从当前可见几何运动到目标；进入与退出使用各自真实或当前可见位置和透明度，不把缺失替换成零。排序条形在过渡中同时更新条长、位置和数值，圆环同时更新弧长与百分比，保留控件和稳定节点。为避免进入、退出占同一位置，本演示在**切换期间**临时错位；位置中间帧并非观测或实际排名。

输入 `scopes` 是各范围的记录，每条需要非空唯一 `id` 和有限的 `x/y`，或两者均为 `null`。排序条示例的 `x` 是数量、`y` 是排序位置；圆环示例的 `x` 是 0–100 的达成率、`y` 是显示位置。`validate` 校验本题实际范围；`render` 由作者把同一帧的值转换为图形和文本。摘要直接使用目标范围真实观测，并标“目标”；中间值标“过渡”。不要把这套演示的静态合成数据当作可接入的真实业务数据。

适配时先检查：① 维度与 ID 的实际含义是否跨期一致；② 数值和基准是否可比；③ 箭头、色彩和临时错位是否会被误读为新增数据；④ 条形比较统一从零开始；⑤ 缺失、进入、退出和真实零是否区分。若比例基准不同、身份不稳定或汇总分母会误导，用标明范围的分层切换或静态方式，不强行动画。多行重排可能产生遮挡；设计临时分道或分阶段并在最终画面实测。

交付前在真实页面检查首次与运行中减少动态、快速反向、焦点留存/被移除时的安全回退，以及 `withStableFrame` 同步回调内稳定导出；动画只针对变化的数据，不能用视觉淡入代替数据连续性。键盘、屏幕阅读器与复杂图元需要另行验证。
