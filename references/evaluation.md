# Evaluation

Separate numerical correctness, reading quality and user acceptance. A runnable chart is not automatically the right chart.

Suggested review weights: business question and comparison 35%, composition and reading 35%, data and definitions 20%, required interaction/delivery 5%, transfer to unfamiliar data 5%. Set criteria before review; do not change weights to obtain a target score.

Hard failures include wrong values, missing-as-zero, undisclosed filtering, incompatible denominators, distorted geometry, causal claims from correlation, blank charts and broken core interactions. A high average cannot cancel these failures.

Verify the requested capability: a picture in PowerPoint is not an editable native data chart. Record save/reopen results when editing is promised. Do not require unrelated formats. Review actual desktop and narrow-screen outputs, not just source text.

Inspect meaningful variants: empty/all-zero/negative input, long labels, missing data, tiny nonzero values, small samples, extreme values and no-result filters. Keep independent review separate from self-checks. This repository makes no external certification or universal superiority claim.
