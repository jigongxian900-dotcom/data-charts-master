# HTML交互、动效、SVG与PPTX

## 按任务选合同

| 任务 | 交付合同 |
|---|---|
| 探索式HTML | 明确哪个操作回答哪个问题；状态、图、摘要、表与导出同步 |
| 叙事式HTML | 每步新增一个判断；同一对象持续存在；滚动外提供按钮/键盘替代 |
| SVG插图 | 自包含、真实文字、viewBox明确、可独立阅读的当前状态 |
| 可编辑PPTX | 默认调用适用且已安装的专用工具，沿用用户已定路线；不把图片插入冒称原生编辑 |

本地制图无需远端服务。单文件要求适用于本地报告；明确要工程化应用时按应用路由。

## 分析交互

先写最多三条使用行为，如“切换总盘/同店，识别增长分化”“选市场，联动缺口与明细”。页面锚点、卡片翻转与悬浮提示不能代替分析交互。

- 状态对象保存过滤、选中对象、排序、指标、时间与缩放域。DOM文本不是数据源。
- 区分过滤与聚焦：过滤改变样本/分母；聚焦只强调对象。界面和导出写清是哪种。
- 联动使用稳定对象ID，不能按数组下标关联。排序后仍选中同一对象。
- 筛选同步更新轴、单位、分母、样本、摘要、表和下载；保留全量原始数据查阅入口。
- 无结果给原因与恢复按钮；未知不填零。重要结论默认可见，hover有键盘/触摸等价路径。
- 密集数据需要局部观察时才加刷选/缩放；比例尺变更有提示和复位。少量类别不为演示功能增加刷选。
- 控件有名称、选中状态、焦点和键盘操作；触摸目标尽量44px。颜色不能单独表达异常或选中。

## 传达信息的动效

先说明目的：对象追踪、尺度转换、排序变化、逐步分解或差异定位。标题飞入、全图淡入、粒子背景不算数据动效能力。

1. 保存旧场景与目标场景，按业务ID匹配；新增/退出单独处理。
2. 共同编码下插值几何；度量/尺度变化先标新轴与单位。过渡中间帧不是新观测，不能像真实时间轨迹一样解读。
3. 典型交互250–600ms，按距离调整。默认不自动循环、不发声音、不接管滚轮。
4. 快速操作取消旧过渡，从当前帧走向最新目标；过时回调不能覆盖新状态。
5. `prefers-reduced-motion: reduce`直接到最终状态，完整信息保留；运行时偏好变更也响应。
6. 导出、打印与交付截图取稳定状态，不能把半帧写入SVG/PPTX。

实际检查开始、中间、结束、快速反转。CSS存在transition不等于动画有效；至少抓到一帧几何中间态。记录目标浏览器与设备，别宣称全浏览器性能已测。

## SVG生产

- 明确宽高/viewBox；填充、线、字体显式设置。来源、期间、单位、合成标志随导出携带，title/desc说明编码与边界。
- 保留真实文本与精确矢量几何。数字不转曲；接收端字体不可假设存在，必要时嵌入有许可字体或核实回退。
- 导出不依赖页面CSS；内联必要样式，排除脚本与UI控件，不用foreignObject承载关键内容。
- id唯一，内部href/url引用可解析；clip范围明确。渐变/透明度不改变数量边界。
- 无外部链接、远端图片/CSS/字体、事件属性和脚本；数字有限、尺寸非负。XML通过仍要看实际尺寸的裁切/碰撞。
- Canvas若不能导出矢量，重绘同一场景或明确交付位图；SVG中的位图不冒称矢量图。
- 转PPTX先核支持集，滤镜/混合模式无法保留时明确降级；先核一页再扩展。

轻量检查：`uv run --no-project python scripts/validate_svg.py chart.svg`。仅检查结构、自包含和可疑数值，不判断数值正确、字体可用或审美。

## PPTX原生编辑

先区分需要：文本/形状可编辑，还是“编辑数据”后能重算。两者分别验收。

- 普通柱/线/散点需要改数据时优先原生图表+内嵌工作簿。精细定制图若重建为原生形状，只能承诺元素可编辑，不能承诺自动重算。
- HTML的hover/刷选/滚动不原样搬入PPTX；按管理判断选择关键稳定状态，必要时用原生Morph/对象动画，保留静读结果。
- 整张SVG作为图片插入只证明矢量保留，不证明对象编辑。用户要求视觉优先时，可使用高清图形层配可编辑标题/注释；另交独立SVG与源数据。明确图形层是SVG还是位图，不将其称为数据可编辑。
- 默认走ppt-master现行路线与检查点，不重启弃用链；不编造确认文件或用诊断参数绕过发布检查。
- 先查包结构、数值和形状/图表类型，再PowerPoint打开→修改代表标签/数据→保存→重开。仅有包检查时标Office未测。
- 字体替换、透明度、文本基线、路径和滤镜需对照导出截图。文件可打开不代替视觉核验。

用户要求不占用电脑操控时，优先现有文档接口或Office官方后台文件API；打开专用验证副本时不显示窗口，不发鼠标键盘或激活窗口。记录实际引擎、修改、保存、关闭、重开和引擎导出的图像。后台验证不等于人工点选体验验证；没有可用后台路径时保留真实待验项，不自行接管用户窗口。
