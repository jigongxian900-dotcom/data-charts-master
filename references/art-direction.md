# Art direction

Start with the relationship that deserves the main visual: difference, distribution, trajectory, composition, flow or hierarchy. Make the title, primary chart, annotations and provenance form one reading path.

1. Define the business comparison, baseline and intended decision.
2. Select a reference that solves a similar reading problem; inspect its geometry and labels, not just colors.
3. Design the main visual before adding containers. Use small multiples when overlap hides comparison.
4. Set type size and density for the actual output. Recompose the phone view rather than shrinking a desktop canvas.
5. Use one coherent semantic palette. Brand red is a focus color, not automatically an adverse result.
6. Compare real drafts when the visual direction is uncertain. A second draft should change reading structure or comparison, not merely hue.

Do not force every chart into cards, posters, a scatterplot or a flow diagram. Decorative effects must preserve quantitative geometry and stable exports. See [visual references](visual-reference.md) and [Tableau case reading](tableau-dashboard-reading.md).
