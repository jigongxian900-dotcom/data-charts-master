# 按问题选图

先写读者问题，再看数据条件。这些是候选，不按数据量强制套图。

| 问题 | 优先候选 | 避用与核对 |
|---|---|---|
| 谁高谁低，差多少 | 排序横条、点图 | 长中文用横向；多类目保留全量表；时间与自然顺序不强制按值排 |
| 怎样随时间变化 | 折线、小多图、短序列柱 | 真实日期间距、缺测留空；过密拆分，不固定三年窗口 |
| 当前相对目标或基期 | 基准线、子弹图、哑铃 | 目标、分母与方向；降低类指标不能高就算好 |
| 哪些项目解释差异 | 瀑布、贡献条 | 起点+贡献=终点，可加且同单位；相关因素不冒称贡献 |
| 构成及其变化 | 100%/绝对堆叠条、少类目饼图 | 同分母、互斥；精确比较内部段时改点图/小多图；华夫不伪造个体 |
| 分布与组间差异 | 原始点+箱线、直方图、ECDF | 小样本展示原值；写分位数与须；小提琴披露带宽，不先加显著星号 |
| 两变量关系 | 散点、分组散点 | 样本、单位、离群值；密集可聚合；回归线需真实统计依据 |
| 多组趋势比较 | 共享尺度小多图、少量折线 | 同刻度与期间；独立尺度只比形状 |
| 哪些阶段流失 | 阶段条+转化率、漏斗 | 同批次、去重和时间窗；阶段存量不能叫转化 |
| 层级或流向 | 树、矩形树、桑基 | 核对层级与守恒；路径太密改表或拆图 |
| 哪里集中 | 地图、位置图 | 地理关系须影响问题；比地区数值通常横条更直接 |
| 分类矩阵差异 | 热力、点矩阵 | 顺序/发散色有语义，缺失独立编码，排序有理由 |

## 组合图与特殊图

看板的KPI迷你趋势、同比环比、达成环、蝴蝶、cohort和复杂组合，按 [看板常用图型](dashboard-chart-patterns.md) 核对业务条件。不能把普通环形构成图直接当目标进度，也不能把一个没有比较依据的大数字称作完整KPI。

先问组合比拆图多带来什么。同单位的点+线可共享轴；不同单位优先共享时间轴的小多图。确需双轴时写单位与范围，避免任意轴范围制造同步。Leon的4–5条系列提示是检查触发，不是硬上限。

弦图、径向、流带、蜂群、华夫、平行坐标可用，但说明比普通图多揭示什么、怎样解码、手机/静态怎样读。无收益就简化。按需查 [FT Visual Vocabulary](https://ft-interactive.github.io/visual-vocabulary/) 与 [From Data to Viz](https://www.data-to-viz.com/)。
