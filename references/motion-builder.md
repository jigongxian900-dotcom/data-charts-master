# 有界业务动效构建器（本地试验）

当任务已经明确为 **1–2个排序条或0–100%目标达成图**，且有2–4个可比较期间、稳定对象ID时，可以直接运行：

```powershell
python scripts/motion_builder.py input.json output.html
```

输入参考现有任务验证 `upgrade-motion-builder-20261117/a.json`、`b.json`。顶层必须有 title、source、charts；每图需要 type（ranking/attainment）、title、unit、definition、comparable=true、scale_max、states。每个期间为对象列表，每条含 id、label、value；value=null明确未报，缺席对象是不在范围，0是真零。ranking每期最多8条，attainment最多4条且单位为%和上限100。不支持负值、超额完成、混口径、自动聚合或任意复合图；遇到这些情况回到自主renderer，不改数硬塞。

生成物自包含，保留所有期间对照表。稳定对象按当前几何与读数同步过渡；进入退出不插造观测；快速反向从当前状态继续；运行时减少动态立即落在目标；打印请求稳定帧。SVG聚焦提供值，按钮支持键盘。表中原始观测不随过渡插值。

此路径降低接线成本，不替代业务理解、选图和审美。先判断连续追踪是否真有帮助，不强迫所有图运动。生成后仍须无头浏览器检查几何/读数中间帧、反向、缺报、焦点、减少动态与打印，以及桌面实际视觉。已通过的机制测试不能替代全新业务题独立盲测。

已知边界：长对象名称和密集进入退出可能拥挤；示例仍有固定绿色与圆角布局，并非所有业务的推荐视觉；复杂组合不由此生成。不得据此宣称95分、普遍稳定或胜过Lieflat。
`n数值边界：仅接受有限且绝对值不超过 JavaScript 安全整数上限的数值。图形读数最多8位有效数字；全期原始表保留输入数值，不用图形读数的舍入值替代。打印前暂时展开源表，打印结束恢复。
