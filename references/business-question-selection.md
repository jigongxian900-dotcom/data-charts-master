# 从业务判断选择图表

核心不是“有时间字段就折线”。先问这张图要帮助读者作什么判断，再决定哪一种比较必须可见。

## 一张关键图的简短规划

在制作前明确：**业务问句 → 管理判断 → 要比较的量与基准 → 首选图及理由 → 易误选的图漏掉什么 → 必须出现的例外/标注**。通常几句话即可，不为每图新增冗长表单。

例如：“优先补哪个国家的目标缺口？”若目标是追回大区营业额，先比较同币种的绝对目标差额，并列达成率补背景。按营业额排名只能说明规模；只按达成率排可能把小体量国家放在最前。若问题改成资源公平或低达成区域辅导，达成率排名可能更合适。同一数据的首选图会随决策变化。

## 业务问法与易误选项

| 问法 / 管理判断 | 关键比较 | 首选候选 | 常见误选与缺失信息 |
|---|---|---|---|
| 优先补哪些目标缺口 | 实绩−目标的绝对差；同时看规模 | 差额横条+目标/达成率数值列 | 规模榜答不了差额；只排达成率忽略分母大小 |
| 谁贡献了增长或拖累 | 同范围增减额，而非增长率 | 增减贡献条；可加且对账时瀑布 | 增长率榜可能高估小基数；瀑布不能装相关因素 |
| 今年是否改善 | 同期、季节性、完整窗口 | 同月对齐折线/共享尺度小多图 | 只画今年从年初到年末，容易把旺季当改善 |
| 总量增加，为何店效下降 | 总量、营业店日、单位表现的同范围关系 | 总量与分母并列；经核对的算术分解 | 单画同比或只看同店，无法排除新店与结构影响 |
| 大多数门店都变好了吗 | 全量门店变化的分布、中位数、正负数量 | 原始点/ECDF/箱线配原值与零基准 | 平均数遮住多数和长尾；小样本小提琴可能夸张形状 |
| 新店是否在爬坡 | 对齐店龄、批次、同城参照与样本变化 | 店龄对齐曲线/批次小多图，附样本量 | 日历月均值混入不同店龄；只画存活门店可能有选择偏差 |
| 是订单还是客单变化 | 同范围总量、每店每日订单数、客单价 | 共享时间轴小多图；算术分解按正式方法 | 双轴任意缩放会制造同步；相关趋势不自动解释原因 |
| 产品/渠道结构怎样变 | 各部分占比与总量，是否同分母 | 100%堆叠+总量；必要时绝对值小多图 | 饼图多时点难比；只看占比忽略总量收缩 |
| 哪个环节阻塞 | 同批次阶段转化、等待时间、存量 | 阶段条+转化/耗时并列 | 阶段存量做漏斗容易误写流失；节点装饰不揭示瓶颈 |
| 价格或投入与结果有关吗 | 逐对象两变量及异常、样本 | 散点+分组，必要时按规模编码 | 双轴时序不回答横截面关系；相关不等于因果 |
| 哪些地区需要覆盖 | 空白、距离、位置/地理约束 | 有合法坐标的地图+可核对表 | 只是比较地区高低时地图会增加解码成本 |
| 活动是否有效 | 可比窗口、对照、净效果与不确定性 | 原始走势+对照/效果区间 | 前后哑铃只显示变化，不能单独支持活动因果 |

上表提供表达思路，不是完整图型清单，也不替代正式指标与分析方法。多个关系须共同判断时，按 [组合推理](composition-reasoning.md) 自主设计。指标尚无正式定义时说明未知；可以透明提出候选定义与取数可行性，正式口径变更沿用既有授权，不能把候选口径写成已确认事实。

**解释贡献与排查风险分开**：贡献榜回答谁带来最多绝对增量，不自动决定风险排查或资源投入顺序。风险队列需明确风险条件，如总盘上升但同店下降、P90恶化或超过服务阈值；与贡献队列分别标注。没有利润、投入与约束，不把两者改写成投资优先级。

**视角变化可以换图型**：从增量构成转到缺口追赶时，重新按比较关系选图。排序差额用共同零线条形，邻近列目标/实际/达成率；不因上一视角用了汇流或气泡就强行沿用。

## 审美如何服务判断

1. **主比较占最大空间**：缺口用长度与共同零线，趋势用连贯时间，分布用位置；标题和旁注承担解释，不让装饰图抢位置。
2. **基准可见**：目标、零、同期、中位数或参考群体必须明确。不能靠一句文案弥补图上不存在的比较。
3. **重点少而准确**：按业务判断强调一两组或一个区域，其他保留。重点不等于所有最高值都高亮。
4. **精度有层级**：图先呈现关系，关键值直接标注，完整值在邻近表中可查。选择有效精度、自然刻度与可读单位，不把每个小数全塞进图。
5. **构图随任务变化**：趋势可宽幅；排名可竖向；分布保留长尾；组合图把主体、基准和例外分清。不是每图都套同尺寸卡片。
6. **整体节奏**：重要问题给大图；补充小图邻近主图；文字像图注而不是重复朗读数值。长文中混用全宽、并列与细节区，但语义和字体统一。

## 同数据对照的验收

让读者用10秒回答原问题，并说出主图、基准与例外。如果只能说“好看”，或答案来自标题猜测而非图形，就继续改选型/编码。视觉稿先以代表页让用户选择；不把主Agent自评95分当作审美认证。
