# Tableau案例的可借之处

2026-11-12研究实际图面后提炼。以下是具体默认状态的观察，不是对作品全部交互、手机或统计口径的认证。作品认可身份与借鉴价值分开记录。

| 具体来源 | 借鉴 | 不能直接照搬 |
|---|---|---|
| [Super Sample Superstore](https://www.tableau.com/data-insights/dashboard-showcase/superstore)；[实际图](https://public.tableau.com/views/SuperSampleSuperstore/SuperDescriptive?:showVizHome=no) | 同一指标的当前值、比较、趋势和区域分组沿同宽列阅读；当前深色、历史浅色 | 看到的细线是Prior Period，不是目标；区域选择不是主要问题时不必加地图 |
| [Big Numbers KPI Dashboard](https://public.tableau.com/views/BigNumbersKPIDashboard/SalesKPIDashboard?:showVizHome=no) | 大值与变化量邻近，当前线与历史面积双重区分 | 不因标题标签就称获奖；百分比与百分点仍须明确，不照搬省略单位 |
| [Airline Alliance](https://public.tableau.com/views/AirlineAllianceActivityDashboard/AlliancePage?:showVizHome=no)；[官方VOTD介绍](https://www.tableau.com/data-insights/dashboard-showcase) | KPI—12期趋势—同类分组的同一行阅读链；多指标同行比较 | 官方已说明是虚构联盟，不能当真实经营成果；vs PM不是目标，密集桌面页不能整体压成手机小字 |
| [Finance Dashboard](https://public.tableau.com/views/FinanceDashboard_17885229519660/Dashboard1?:showVizHome=no)；[官方分类页](https://public.tableau.com/app/discover/business-dashboards) | 实际目标对比采用相邻标注与共享尺度，颜色重点克制 | 构成环不能当目标达成环；官方分类收录不等于VOTD，雷达也不是多指标默认首选 |
| [官方精选作品集](https://www.tableau.com/data-insights/dashboard-showcase)中的Shipping KPIs、Telecommunications、Customer Satisfaction、Sales Commission | 紧凑KPI与分解图建立不同密度，比较线、区间与类别身份分工 | 只看到官方预览的部分不能声称交互已验；两侧不同单位的并列图不能当共同轴蝴蝶图 |

## 采用到新图的六条规则

1. 当前值、同比/环比、趋势、分组贡献连成阅读链，保留各自单位与比较期间。
2. 品牌重点色与有利/不利状态分开，历史基线降低强调但仍可读。
3. 每条基准线写清是目标、上期还是去年，不因线长得一样就混称。
4. 单项达成环交代实际、目标、率与超额；多对象精确比较优先排序子弹或条形。
5. 蝴蝶两侧同单位同尺度，类目居中、绝对值与差值可查；不把布局负坐标说成负值。
6. 组合页按问题组织，手机重排成连续阅读链，图表筛选和KPI分母共享状态。

外部原图只作研究依据，不复制成新图资产。新样例使用合成数据，是否更好以新图实际阅读、口径与交互证据判断，不靠“Tableau风格”名称加分。
