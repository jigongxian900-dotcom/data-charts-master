# Visual references

Study business questions, reading order, encodings, scales, direct labels, density and interaction. Reference links are not permission to copy protected code or artwork. Official selection, popularity and contest awards are different signals; none replaces testing your own chart.

- [Tableau showcase](https://www.tableau.com/data-insights/dashboard-showcase): executive reading paths and overview-to-detail relationships.
- [Tableau design practices](https://help.tableau.com/current/pro/desktop/en-us/dashboards_best_practices.htm): audience, purpose and device size.
- [D3 gallery](https://observablehq.com/@d3/gallery): inspect specific executable examples for scale and state behavior.
- [Visual Cinnamon](https://www.visualcinnamon.com/): custom visual language with explicit data relationships.
- [WCAG contrast guidance](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): context-sensitive text contrast; contrast alone is not full accessibility.
- [Lieflat Charts](https://github.com/larashero3-dotcom/lieflat-charts), [Diagram Design](https://github.com/cathrynlavery/diagram-design), [Vivid Figures](https://github.com/yjz211/vivid-illustration-skill): storytelling, explanation and figure composition. Respect each project’s license.

No upstream source or artwork is bundled. See [notices](../THIRD_PARTY_NOTICES.md).
