# B03 · 冷藏原料的到期与缺货权衡

本题数据全部为原创合成数据。它不代表任何真实组织。

## 工作问题

仓储负责人要在未来10天安排优先消耗与有限调拨。请区分总库存充足、某日不可用和即将到期的风险。按先到期先出模拟三个给定需求情景，追踪同一批次从原数量到售用、到期和期末剩余。找出应先人工复核的地点和品类。调拨只有每站每日最多20件的候选限制，可提出候选，不要伪造最优解。

## 数据定义

- qty 为 as_of 当日盘点/已确认在途的件数。available_day=0 表示当前可用。
- 每日开始先接收当天到货。expiry_day 当天仍可使用。当天结束后清理到期余量。
- 每天按 expiry_day、lot_id 顺序先到期先出。相同品类与地点才可直接满足需求。
- low、base、high 是给定需求情景，不是概率分布或承诺预测。
- unit_cost_cents 是每件账面成本。到期损失按剩余件数乘成本。
- 期末剩余是第10天清理到期后仍有效的库存。

## 证据边界

没有运输时长和运费。默认模拟不调拨。候选调拨须标注未验证可达性。不得把三情景画成统计置信区间。
