# B02 · 双因素触达实验的投放决策

本题数据全部为原创合成数据。它不代表任何真实组织。

## 工作问题

增长负责人要决定是否推广消息、补贴，或二者同时使用。请比较购买效果和净贡献，并检查效果是否随市场、用户类型改变。要能从整体切入一层人群，切换绝对效果与相对效果，同时持续认出同一实验组合。请指出数据不能支持的路径解释。

## 数据定义

- assigned 是随机分配用户数。purchased 是14天内至少购买一次的用户数。
- opened、clicked 是相应行为的去重用户数。它们是独立边际汇总，不提供用户交集。
- 金额单位为分。净贡献候选定义为 revenue_cents 减三项已知成本。该定义不含商品成本。
- message、credit 各为0或1。00为共同对照。比较必须说明对照与分母。
- 可用购买二项分布估计不确定性。收入只有汇总金额，未提供个体方差。

## 证据边界

不得把 opened、clicked、purchased 画成已知的逐人转化路径。不得据汇总金额伪造收入置信区间。随机化支持该实验范围内的购买对比，不保证外部市场可迁移。

## 交付与操作

请自主选择表达方式。不得询问评委想要哪一种图。
交付可运行的分析页面、源数据下载和使用说明。
页面要让负责人从总体判断进入具体对象，再回到总体。
请支持桌面、手机、键盘和触摸操作。
要能筛选、聚焦、比较、复原和导出当前状态。
空结果要解释原因，并保留恢复入口。
连续切换时，页面必须保留正确的对象与当前状态。
请让有分析价值的状态变化可追踪。尊重运行时 reduced-motion 设置。
导出和打印必须对应一个完整、已稳定的状态。
不得用装饰动画代替业务分析。可以说明某项动画不适用的原因。
