# Jee Charts Master · 十二图动效展厅

打开 `index.html`，向下浏览即可。绘图区进入视野后播放一次。所有源数据内嵌，页面可离线打开。图后「查看数据」可以逐条核对原始合成数据，支持键盘。

| 读者要看 | 图型 | 动效 |
|---|---|---|
| 订单从哪来、去了哪 | 流向带 | 按已知路径移动的亮点，流带宽度保持真实 |
| 需求如何长起来 | 面积折线 | 沿真实时间方向揭示，尾标随线到达 |
| 谁的位置变了 | 排名迁移 | 同一实体沿自身路径走到新位次 |
| 利润如何一步步算出 | 瀑布 | 门类贡献接到前一终点，各自落位 |
| 未达和超额分别有多少 | 发散条 | 从共享零线向两侧延伸 |
| 与目标还差多少 | 子弹图 | 保持目标固定，实际条和端点进入 |
| 份额如何重分配 | 百分比堆叠 | 边界一起迁移，总宽守恒，标清过渡示意 |
| 哪项占过半 | 环形 | 依次描绘真实圆弧，中心只显示原数 |
| 库存金额集中在哪 | 矩形树 | 展开区域，稳定后面积对应份额 |
| 高投入门店产出是否分化 | 散点 | 按顺序显现真实样本，点的坐标不移动 |
| 哪几个时段较忙 | 时段矩阵 | 工单从早到晚显现，未报保留斜纹 |
| 比较还存在哪些不确定性 | 点区间 | 先显示点估计，再展开已知区间端点 |

从此目录运行 `python build.py` 重建独立 HTML。更换数据时逐图核对图域、参照值、注释和真实的动画终点。展厅是固定题材的设计样例。同格式生成其他业务图时，沿Jee Charts Master的对应生成或自定义入口制作。
