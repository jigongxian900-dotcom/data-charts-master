# 复合诉求与联合办理

全部数据为原创合成数据，不代表真实组织。此例回答：按完整标签集合去重，联动请求规模、紧急未结、投入工时及等待口径。

这是固定数据与固定问题的可复现作品。`producer.py` 仅重建本例，不是适配任意 JSON 的通用生成器。

## 查看与重建

直接打开 `artifact.html`。页面可离线运行，不需要安装第三方包。

在本目录运行：

```sh
python producer.py
```

在仓库根目录重建三例及网站副本：

```sh
python scripts/rebuild_desktop_examples.py
```

运行条件：Python 3.10 或更高版本，仅用标准库。源文件与本地依赖位于同一目录。

## 文件与来源

- `input/brief.md`、`input/data.json` 保留原始题目和数据字节。
- `source.json` 是制作器实际读取的数据，保留原始字节。
- `computed.json` 记录派生值和独立重算检查。
- `artifact.html` 包含页面、数据、交互与导出。
- `provenance.json` 记录冻结原件与公开派生的独立 SHA-256 及允许差异。

公开派生只调整输出换行为 LF。业务算法、数据、HTML DOM 和可执行脚本保持等价。整个 HTML 的字节不一定与原件相同。
