# 交互与数据动效示范

三个离线HTML使用相同八市场合成数据。用于学习具体实现，不是自动换数模板，也不是已获接受的通用风格。

- `dir-1.html`：增量汇流/排序缺口条切换，带宽插值、市场聚焦、表格联动、SVG导出；缺口采用共零基线。
- `dir-2.html`：总盘/同店气泡探索，横轴指标切换、排序、市场联动与稳定态导出。
- `dir-3.html`：规模→增量→同店，持续对象与阅读叙事、按钮和滚动驱动、稳定态打印。
- `spec.json`：完整来源、单位、期间与数据。

普通图优先轻量脚本。复杂交互按目标选择实现，不强制用这三种结构。样例中故事按固定数据编写；换数据时重算标题、摘要、轴、单位、样本、注释与导出元信息。

公开版本的实际检查范围见 [验证记录](../../docs/validation.md)。
