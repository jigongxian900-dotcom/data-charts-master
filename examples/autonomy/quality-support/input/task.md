# 精密陶瓷：两组工艺支持人员先去哪里

本题使用合成数据。截止日为2026-11-13。

工艺负责人只能向两个生产单元各派一组支持人员。业务要求先支持“每个完整观测日，检验异常件数超过2%基准的差额”最多的两个单元。请按该目标排序，结合较前期的异常率变化解释取舍。

quality_daily.csv 每行是一个生产单元的完整检验日。produced_n是当天生产件数，inspected_n是当天完成检验的件数。两者不是同一个分母。检验覆盖不保证随机，不能把检验结果直接外推到全部生产件。

scrap_n和rework_n是完成检验件中的两种互斥处置。异常件数等于两者之和。本题检验异常率等于异常件数除以inspected_n，越低越好。2%是本题业务比较基准。返工工时rework_hours是辅助指标，不参与异常率的分子。

本期从11月2日开始。各单元连续上报天数不同。缺行表示未上报，不是零。字段空白表示未知。数字0表示真实观测零。

前期从10月5日开始，和11月2日同为星期一。每个单元按本期连续完整观测的前N日，对齐前期从10月5日起的前N日。不能直接比较整段10月数据，也不能用两个月同一日号代替对应期间。

优先级按本期观察到的平均每日基准差额计算：max(本期异常件数−2%×本期检验件数,0)÷完整观测日数。基准差额可为小数。它不等于已经确认能消除的异常件数，也不是预测下周收益。

请在一个主图中组合本期检验规模、异常率与2%基准、较前期变化以及不同覆盖天数。编码由你自主决定。优先级指标须能读到精确值。简单拼接三张普通图不满足本题主图要求。

请保留真实零异常、零处置及返工工时未知的区别。回答能否由这些记录证明所有单元本期返工总工时已经准确掌握。不要把工时空白填成零。

交付可离线打开的单文件HTML，包含源数据、精确值查询及computed.json。首次渲染前保存plan.md，说明标记、尺度、组合方式及放弃的备选。decisions.md说明两个支持对象、行动条件及复查指标。
