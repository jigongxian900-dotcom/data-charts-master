# H02 决策与计算

本题全部为合成数据。期间 2026-11-02 至 2026-11-08，当地时间，7 个完整自然日。

## 试点

在 flexible=1 且用途为 HVAC 的设备组内，选择 **North / Lab / HVAC**。该组峰价用电 **2,240 kWh**，本周总用电 **6,720 kWh**。此选择只依据峰价用电规模与输入资格；没有舒适度、移峰容量和改造成本证据，不能把其改写为净投资回报最优。

## 情景

16、17、18、19 时为峰价，2 能源点/kWh；其余时段 0.5 能源点/kWh。移峰量 = 2,240 × 20% = **448 kWh**。假设同量用电全部转至平价，且总用电不变，节省 = 448 × (2−0.5) = **672 能源点/同样七天**。所选组基准能源点为 6,720，情景后为 6,048。这是可复核的合成情景，不是已实现收益，不是因果评估，不自动外推下一周。

## 执行与复查

设施负责人先核实该组的可调节容量、舒适度/工艺约束与设备安全运行窗口，再确定平价承接小时。输入未指定具体平价小时，当前图只展示基准用电，不伪造情景后的小时分配。

复查同组：16–19 时实测 kWh、平价时段新增 kWh、全天 kWh、移峰率（峰价减少量/可比基准峰价 kWh）、按同价格重算的能源点、温控/工艺约束违例。基准须匹配工作日、天气和占用，保留对照或适当设计；前后差异不能直接称为净效应。

## 口径与覆盖

原始观测键为 campus/building/use/date/hour，1344 行，8 组，各 168 小时；缺测 0，重复键 0。零值单独计数，未用 0 补缺测。主图每个色块是同组同小时跨七天的总 kWh，不是日均，也不是瞬时功率。半径仅排序层级；扇区面积没有数量语义。午夜方向相邻：23:00–23:59 后接次日 00:00–00:59；一周合计时钟不表示各日之间的实际轨迹。

## 对账

所有楼宇、校区及全园合计与 control_totals.csv 对账，差值均为 0；明细见 computed.json.reconciliation。

### 自查发现与修复

1. 首轮源下载对比失败：Python 文本读取规范化 CRLF，未完整保留源字节。已改为 read_bytes 解码后内嵌，保留 BOM 与 CRLF；后台浏览器下载后与原始 CSV 逐字节相同。第二次失败来自旧断言仍去除 BOM，已修正为 Buffer.equals。
2. 单独 SVG 在 Edge 中 fullPage 截图超时，等待字体完成后仍未返回。改用固定视口截图，文件实际打开及图面已查看。此问题属于截图路径，未将超时伪装为成功。
3. 最初 Node 探针多写一个右括号，语法错误；随后直接运行检查文件成功，不涉及产物计算。
4. 可调标识以邻近层级树的文字为准，删除图注中不可靠的粗边声明。
5. 稳定 SVG 由 producer 提取 HTML 中的同一渲染函数，在 Node 中执行生成；无需手动改路径或另写一套几何。重建命令：uv run --no-project python producer.py。Python 与 Node.js 为重建依赖，HTML/SVG 阅读不依赖它们。

6. 浏览器与 Node 的三角函数末尾浮点差异造成 SVG 字节不同；将坐标统一四舍五入至小数点后六位后，下载 SVG 与 producer 的 SVG 逐字节相同。
7. 320px 初查暴露轨道标签过密风险；移动端改用独立半径、层级间距与标签位置。已在 320/360/390px 重新截图和目检。
