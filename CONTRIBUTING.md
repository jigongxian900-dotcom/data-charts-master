# Contributing

Start with the business question and a minimal reproducible example. Use synthetic or properly licensed public data. Include units, period, scope and denominator.

For visual changes, include desktop and narrow-screen captures. Preserve missing-versus-zero behavior, keyboard operation, reduced motion and print readability. Rebuild generated files and run the validation commands in README. Do not submit private operating data, credentials or third-party artwork without permission.

## Contributions after v5.3

New contributions must have a clear rights basis compatible with the noncommercial and separately negotiated commercial-permission model. Do not submit proprietary templates, restricted assets, or code you cannot authorize. A PR alone is not represented as granting an unrecorded commercial relicensing agreement; the maintainer may request a separate contributor agreement before accepting material that needs such rights. Historical contributions and MIT notices retain their existing scope.
