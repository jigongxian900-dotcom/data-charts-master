# KPI builder 独立候选

本候选只负责预先聚合指标的可靠呈现，不是完整业务分析或自动看板引擎；未合并真源，未发布 GitHub。

## 用法

```powershell
python kpi_builder.py demo.json output.html
python test_builder.py
node verify.cjs
```

仅 Python 标准库生产；验证需要现有 Playwright + Edge。HTML 零网络请求，不需要服务端。无需抢用户桌面。

## 数据契约

输入：`title, scope, source, states[]`。每个 state 有 `id,label,metrics[]`。所有状态保留相同指标身份、顺序、单位和方向。

每个 metric：`id,label,value,unit,kind,polarity,period,definition`；kind=`number|percent`，percent 用百分数值（5.1 就是5.1%，不是0.051）；polarity=`higher|lower|neutral`；value 为有限数字或 null。

可选：`precision`（0—6）；`comparison:{label,value}`；`trend:[{date,value}]` 与 `trendLabel`；`target` 与同期间 `targetPeriod`。

- target 字段存在：目标卡；未知目标/零目标显示原因，不计算比率。
- 无 target、trend 非空：趋势卡；缺报断线，孤点保留，常数序列扩展范围。
- 两者均无：数字降级，不添装饰图。
- 不支持负目标、跨期目标、不同对象集合；拒绝而非猜测。
- 率类差额用百分点；非正基期不计算常规增幅。
- 超大数主读数使用中文紧凑记数；详情/下载保留原数据，悬停值提供按精度格式化全值。
- 支持有符号实际值子弹图，实际条从零线起；目标线与实际条角色不同。
- lower 的目标是上限，显示满足/超过上限及差额，不使用“达成率”；neutral 只显示参考差，不判优劣。higher 且目标正数才计算达成率。
- 详情的当前、基期、目标和趋势读数使用原始数值字符串，不按展示精度舍入；非零极小值不显示为零。派生比率非有限时显示不可表示，极大有限比率用科学记数法。

## 交互与动效

键盘可切换期间、打开/关闭详情；Escape 后焦点返回触发按钮。重绘保持按钮身份焦点，已打开详情同步。

相同指标数值可连续过渡，子弹图几何与读数同帧。中间态明确标为过渡值，趋势/比较为最终选择期间。若旧值超出新尺度，直接切换，避免越界；缺报也直接替换而不从零插值。初始/运行时 reduced-motion 直接终态。打印、导出强制终态，JSON 下载包含所选状态的原始数值。

## 本轮验证

Python：4测试方法，其中拒绝测试含9个非法输入子例，另测巨整数正常拒绝。
浏览器：`verification.json` 记录32项检查；`verification-review.json` 另记11项独审缺陷回归；零外链、零页面错误。两领域合成数据：配送业务、水处理厂；另有长文本、大数、缺报、负值、零目标、零基期、单点/常量序列和注入字符串边界夹具。运行时 reduced-motion、10次快速切换、反向、真实中帧几何/读数、详情同步与下载均已运行。

桌面1440/1280/1600和基本390宽度无页面横向溢出。文本放大测试不冒充实际浏览器200%缩放。`demo-desktop.png`、`edge-desktop.png` 和 `water-desktop.png` 为真实无头渲染。

保留失败：普通沙箱写指定D盘任务目录被拒；使用已授权的提权运行后成功。没有改动测试来隐藏权限错误。目视发现大数换行不美观后改为紧凑显示；缺失/零目标不再留下空SVG图位。

独审另发现四项真实缺陷：低优目标错误称达成率、详情小数舍入、极小目标派生溢出、巨整数OverflowError，已修并保存原始候选于 before-review-fixes。作者专项测试第一轮错误地把1/1e-300×100当成浮点溢出（实际1e302仍有限），该断言失败已保留此记录；改为1e15/1e-300的真实溢出输入，并增加有限巨比率的科学记数法。修后需独立复验，作者回归通过不替代独审。
